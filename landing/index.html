What it does

Separate accounts that never bleed into each other.

Truly isolated

Every profile gets its own data directory — separate login, chat history, cookies, and MCP settings. Nothing from one account is ever visible to another.

Run them together

No single-instance lock. Open Work and Personal at the same time — each in its own Dock icon and window.

Colour is identity

A tinted icon and accent per profile, plus a green dot when it's running. Know which account you're in at a glance.

Made for the keyboard

⌘N for a new profile, ⌘L to launch, ⏎ to open, ⌫ to remove. Search and switch without touching the mouse.

Local & private

No account to create, no server, no telemetry. Personae just orchestrates the Claude Desktop you already installed — everything stays on your machine.

Feather-light, survives updates

A tiny native app built on Tauri — a few megabytes, not another Chromium. It wraps your installed Claude, so it keeps working after every Claude auto-update.

Three steps

From one account to many in under a minute.

STEP 1

Name a profile

“Work”, “Personal”, a client — whatever you juggle. Pick a colour, or let Personae choose one for you.

STEP 2

It carves out a space

Personae creates an isolated data directory and a tinted app icon, then registers it with your system so it shows up in Spotlight and the Dock.

STEP 3

Launch & sign in once

Open it, sign in, and it stays signed in — in its own window, forever. Repeat for as many accounts as you need.

FAQ

Running multiple Claude accounts, answered.

Can I run two (or more) Claude accounts at the same time?

Yes. Personae has no instance limit — open as many Claude Desktop accounts as you like, all at once, each in its own window and Dock icon.

How do I run multiple Claude accounts on a Mac?

Install Personae, click New profile for each account (Work, Personal, a client…), then Launch. Every profile is fully isolated with its own login and history — sign in once and it stays signed in.

Does it work on Windows?

Yes — macOS 11+ and Windows 10+. The same isolation works on both platforms.

Is my data private? Does Personae see my logins?

No. There's no account, no server, and no telemetry. Personae only orchestrates the Claude Desktop you already installed; each profile's data stays on your machine, isolated from the others.

Will it break when Claude updates?

No. Personae wraps your installed Claude rather than repackaging it, so it keeps working after Claude's auto-updates.

Is Personae free? Is it official?

It's free. It's an independent companion tool — not affiliated with, or endorsed by, Anthropic.

First time opening it? Read this

macOS — right-click the app and choose Open, then confirm. (Or go to System Settings → Privacy & Security → Open Anyway.)

Windows — if a blue “Windows protected your PC” box appears, click More info → Run anyway.

Personae isn’t code-signed yet, so the OS shows this one-time warning. It’s safe — the code is public and everything runs locally, with no account or telemetry.
